## About

NavArch Studio is a professional naval architecture management platform featuring:

- Modern web-based user interface
- Microservices architecture
- Cloud infrastructure deployment
- Reference data catalog (hull forms, propellers, water properties)
- Computational tools for naval architecture calculations
