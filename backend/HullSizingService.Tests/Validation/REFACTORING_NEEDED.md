## How to Refactor (Future Work)

### Pattern for Full Pipeline Tests

```csharp
[Fact]
public async Task FullPipeline_GeometryGeneration()
{
    // 1. Create mission case
    var mission = CreateTestMissionCase();
    _context.MissionCases.Add(mission);
    await _context.SaveChangesAsync();
    
    // 2. Use SizingRunService (not just solver)
    var sizingRun = await _sizingRunService.CreateAsync(mission.Id, options, default);
    
    // 3. Query CandidateDesign from database (has GeometryJson)
    var candidates = await _context.CandidateDesigns
        .Where(c => c.SizingRunId == sizingRun.Id)
        .ToListAsync();
    
    // 4. Now can test GeometryJson
    var candidate = candidates.First();
    candidate.GeometryJson.Should().NotBeNullOrEmpty();
    
    // 5. Validate geometry structure
    var validation = _geometryValidationService.Validate(candidate.GeometryJson);
    validation.IsValid.Should().BeTrue();
}
```

### Dependencies Needed
- `ISizingRunService` injection
- Database context with all entities
- Geometry validation service
- Full service pipeline
